# ConnectCulture2.0
O Connect Culture é um projeto digital criado por alunos de Sistemas do Senac Serra Talhada para unir tecnologia, educação e cultura. A iniciativa moderniza o acesso à história local, tornando museus e pontos turísticos mais interativos, acessíveis e atraentes para o público por meio da inovação, enriquecendo a experiência dos visitantes.
